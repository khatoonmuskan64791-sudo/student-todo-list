# Student To-Do List ✅

A simple student project built with HTML, CSS, and JavaScript. It helps students organize assignments, study sessions, and everyday tasks.

## Features
- Add tasks
- Mark tasks as completed or pending
- Delete individual tasks
- Filter by All, Pending, or Completed
- Clear all completed tasks
- Save tasks in the browser using Local Storage
- Responsive layout for mobile and desktop

## Run the project
1. Download and extract the ZIP file.
2. Open the `student-todo-list` folder.
3. Double-click `index.html` to open it in your web browser.

No installation or server is required.

## Files
- `index.html` — page structure
- `style.css` — design and responsive styling
- `script.js` — task management and browser storage

## GitHub upload
Create a repository named `student-todo-list` on GitHub. Upload these files to the repository, or use Git from this folder:

```bash
git init
git add .
git commit -m "Add student to-do list project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/student-todo-list.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.

## Technologies
HTML5, CSS3, JavaScript, Local Storage.
